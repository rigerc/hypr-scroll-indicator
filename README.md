# hypr-scroll-indicator

A [Noctalia](https://github.com/noctalia-dev/noctalia) plugin source with one plugin, also available in the
Noctalia plugin store:

- **[scroll-indicator](scroll-indicator/)**: dots or a line on your bar showing which column you're on in a Hyprland
  scrolling-layout workspace.

Install steps and everything else are in **[scroll-indicator/README.md](scroll-indicator/README.md)**:

- [Usage](scroll-indicator/README.md#usage): enable the plugin and add the `dots` widget to your bar
- [Example setup](scroll-indicator/README.md#example-setup): one 2/3-width scrolling workspace as a
  "drawer" for apps you keep open
- **Visual cues** (optional Hyprland config, the author's favourite part):
  - [Example keybinds](scroll-indicator/README.md#example-keybinds): scroll columns with a small **"bump"**
    at the first/last one, so you feel the end of the row
  - [Drawer bounce](scroll-indicator/README.md#optional-a-drawer-bounce-when-entering-the-scrolling-workspace):
    the scrolling workspace slides in vertically and **bounces**, so it feels like its own place
- [Pairs well with a scroll overview](scroll-indicator/README.md#pairs-well-with-a-scroll-overview): a
  Niri-style overview plugin for the whole row
